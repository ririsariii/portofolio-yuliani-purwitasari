## Overview

Interactive portfolio and technical showcase for **Yuliani Purwitasari (Sari)** — Information Systems graduate from UPN "Veteran" Jawa Timur (3rd Best Graduate, GPA 3.87) and Bangkit Academy 2024 Distinction & Best Graduate of the Machine Learning Path.

Built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, GSAP, Three.js / React Three Fiber, and bilingual localization (`en` / `id`).

## Included Pages

- `/` — Hero, 3D interactive credential lanyard, identity sequence, expertise, featured highlights, GitHub stats (`ririsariii`), and bilingual support
- `/projects` & `/projects/[slug]` — 10 projects spanning AI & NLP (IndoBERT ABSA, Tanamore), Business Intelligence (Looker Studio, AdventureWorks OLAP), and Web/Mobile apps, including local video demos
- `/experience` — Work, certification, and organizational leadership timeline (PT PLN Persero UP3 Gresik, Bangkit Academy, HIMASIFO, BEM FIK, Teaching Assistant)
- `/skills` — Technical stack, analytical/engineering competencies, and tools
- `/achievements` — 3 academic/Bangkit honors and 32 verified credentials with filtering and archival detail view
- `/gallery` — Activity & event photography
- `/blog` & `/blog/[slug]` — Technical write-ups
- `/resume` — Printable CV view generated from `src/data/portfolio.ts`
- `/contact` — Direct inquiry page

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site locally, or build for production with:

```bash
npm run build
```
